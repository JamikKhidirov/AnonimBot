# 🤫 AnonimBot

**Двусторонняя анонимная переписка в Telegram.**

Каждый пользователь получает уникальную ссылку — любой, кто по ней перейдёт, напишет владельцу анонимно, а владелец сможет ответить (тоже анонимно). Полноценный диалог без раскрытия личности.

---

## 🎛 Админ-панель

```
[📊 Статистика] [👥 Пользователи] [✉️ Сообщения] [👑 Админы]
[🔍 Поиск]     [📢 Реклама]     [🛠 Инструменты] [⚙️ Для разработчика]
```

- 📢 **Реклама** — создание объявления (название → медиа → текст → кнопка), редактирование полей, вкл/выкл, установка интервала рассылки, «📤 Отправить сейчас», **👁 Предпросмотр**.
- 🕵 **Журнал действий** (раздел «Для разработчика») — кто и когда забанил, разблокировал, назначил админа или сделал рассылку.

## 🧩 Как это работает

1. Пользователь открывает `/start` и получает ссылку `t.me/Bot?start=<code>`.
2. Аноним переходит по ссылке → создаётся сессия, владельцу приходит «👤 кто-то открыл твою ссылку».
3. Аноним пишет → сообщение **сразу доставляется** владельцу. Аноним может нажать «🗑 Удалить у владельца» — и копия исчезнет у владельца (и из БД), даже позже.
4. Владелец отвечает реплаем → ответ уходит анониму тоже реплаем. Диалог продолжается.

> Кнопка «👤 Кто это?» доступна админам, владельцам Premium Plus и тем, у кого активен реферальный бонус.

## 🗄 Данные

SQLite (async, SQLAlchemy). Основные таблицы: `users`, `chat_links` (+счётчики просмотров), `messages`, `active_sessions`, `forwarded_messages`, `adverts`/`advert_config`, `audit_log`.

## 📁 Структура

```
bot/
├── __main__.py    # точка входа
├── database.py    # модели + CRUD + миграции
├── keyboards.py   # inline-клавиатуры
├── locales.py     # ru / en
├── ad_scheduler.py# рассылка рекламы по таймеру
└── handlers/
    ├── start.py   # /start, deep-link, рефгралы, статистика
    ├── user.py    # /messages, /stats, /setgreeting, /stop...
    ├── anon.py    # анонимки, отмена отправки, альбомы, реплаи

```

Деплой: **Amvera** (авто-деплой из GitHub, SQLite на `/data`). See [amvera.yml](amvera.yml).
